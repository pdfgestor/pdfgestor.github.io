# PDFGestor — SEO e publicação

O pacote mantém o index antigo em `index-original.html` e entrega uma home reorganizada em `index.html`, blog em `/blog/` e 10 artigos em URLs amigáveis.

## Publicação

Copie o conteúdo desta pasta para a raiz do repositório `pdfgestor.github.io` e faça commit/push. O site ficará em https://pdfgestor.github.io/.

## Google Search Console

1. Cadastre a propriedade https://pdfgestor.github.io/.
2. Envie https://pdfgestor.github.io/sitemap.xml.
3. Use a inspeção de URL para solicitar a indexação da home, blog e artigos principais.
4. O arquivo `googlef61385477a9e6238.html` foi mantido no pacote para a verificação por arquivo HTML. Se o Google gerar outro nome ou token para a propriedade, substitua-o pelo arquivo baixado na tela do Search Console antes de publicar.
